记录三轮讨论的演化，避免后面反复推翻。

---

## 第一轮：认知阶梯 + 力学类比（已废弃）

最初方案把报告设计成"从天体力学视角理解 AI"，包含：

- 三个病根：低维强非线性、长时积分、奇点
- AI 介入三层次：L1 代理 / L2 结构 / L3 证明
- 一张"AI ↔ 力学"翻译词典
- "LLM 是打靶法初值猜测器，Lean 是积分器"的比喻

**结论：全部废弃。**

原因：听众是聪明的研究者，类比会被读成绕开机制；一旦被追问就会失真。

---

## 第二轮：直接讲机制（框架保留）

主线改为四层：

```
模型 → 循环 → 验证器 → 训练 → 案例
```

其中"验证器"占 8 分钟，以 Lean 为主。这一版确立了：

- 不做类比
- 讲 agent loop 与 harness
- 讲 Lean 与 RLVR
- 用一个引理做端到端案例

**结论：框架保留，重心调整。**

## 金句库

1. 模型看到的不是文字，是一串整数。
2. Token 是统计上高效的切分，不是语义单位。
3. 同一个词，在模型、账单和登录凭证里叫三个不同的东西。
4. 预训练给知识，SFT 给行为，RL 给搜索与纠错的习惯。
5. RL 不教它新知识，只是把偶然做对变成稳定做对。
6. 数学和代码之所以先被攻破，是因为它们对错便宜。
7. 模型没有记忆，记忆是产品。
8. 能力 = 模型 × 上下文 × 循环。
9. 上下文不是越长越好，是越相关越好。
10. 它没有让创造性变得容易，它让"验证便宜"的领域变得可搜索。
11. 模型提供概率，验证器提供梯度。
12. 模型负责概率，harness 负责必然。
13. 解题可以搜索；做数学需要方向。
14. 下一个定理，仍然从下一个 token 开始。
