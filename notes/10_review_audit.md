## 2. 来源与关键事实

### 四页案例

原文：Addy Osmani、Morgan Westlee Lunt、Qing Wang，[*How the Claude Code team does code review*](https://claude.dev/blog/solving-code-review-at-anthropic/)，2026-10-15。

- 已完整阅读文章，四页均保留可点击出处和团队自述标注。
- 约 2,500 → 30,000 多为 **Anthropic monorepo 每日落地变更**，时间是 2026 年 5–9 月；未写成 Claude Code 仓库的 git commit 统计。
- Claude Code 独立仓库的合并 PR 翻倍与回滚占比下降，是另一组团队观察；没有写成受控因果结论。
- 审查器复核发现、多 Agent 投票不等同于正确性证明。
- 较轻人工审批流程仅对可信作者开放；指定敏感路径与额外分类器可增加审批要求。
- 三轮后的重新考虑属于升级处理规则，不是三轮保证正确。
- 具体科研工作如何迁移留给听众，不宣称案例已验证科研有效性。

## 3. 技术表述修正

- **S9**：区分主动采样、浮点误差与逐次运行的非确定性。固定实现可以确定；logits 接近时数值差异才可能改变贪心排序。
- **旧 S16 / 旧 S17（现备份）**：压缩作为个人解释视角，SFT 也可能学习任务信息；新主讲不展开这些细节。
- **S30**：热图非实测；长度与位置影响依模型和任务而异，避免把一种失效模式说成普遍定律。
- **S40**：模型提议，执行框架组织上下文、状态、工具与检查。功能环不是严格的软件层级。
- **S49**：网页、IDE、CLI 能力取决于配置；文件与检查可复用，但换模型或环境后仍需评测。
- **S50**：早期失败描述为个人结果，避免“必定崩溃”的普遍推论。
- **S51**：能量误差、辛性残差、步长收敛为互补证据。备注明确辛积分器一般不精确守恒原哈密顿量，能量误差小不保证轨道正确。
