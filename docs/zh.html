04 / application

Harness：让概率输出变成可运行的系统

模型会提议；harness 负责让提议合法、可执行、可检查、可停止。

一个受控循环

提议→ 校验→ 执行→ 观察→ 验证→ 继续 / 停止
工程边界

模型只负责生成概率分布与调用提议；
外部环境的安全性与确定性，完全由 Harness 兜底。

不提升模型智力；让错误可发现、可停止、可复现。
01 工具注册与参数校验

输入是否合法、类型是否匹配；非法提议直接拦截

02 沙箱与权限

能做什么、不能做什么；只读/写分离，先限制再执行

03 超时与重试

失败不无限死循环；设置超时熔断与最大重试次数

04 结果验证

结果对不对；通过独立测试与断言检查，不轻信模型自夸

05 回滚与停止

坏了能否退回快照；达到步数或异常时强制刹车

06 日志与复现

记录每一次调用与返回，全流程轨迹可审计、可复盘

模型提供概率，harness 提供边界。
permissions · sandbox · retries · verification · stop28 / 53

05 / AI × math · 搜索的两个概念

DAG 存依赖；MCTS 决定往哪里搜

DAG · Directed Acyclic Graph
有向无环图：一种结构

节点：引理、子目标
有向边：前提 → 结论
无环：避免循环论证；共享节点可复用

MCTS · Monte Carlo Tree Search
蒙特卡洛树搜索：一种策略

节点：状态；分支：候选动作
选择 → 扩展 → 模拟／评估 → 回传
平衡探索与利用，分配搜索预算

DAG 回答“依赖什么”；MCTS 回答“下一步试什么”。
