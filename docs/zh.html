04 / application

Harness：工具不能越界，长时运行能回退

工具在环境里执行；概率输出在长时运行中总会出错。

一个受控循环

提议→ 校验→ 执行→ 观察→ 验证→ 继续 / 停止
两件事

工具不能越界：不能删文件、不能上传公网。
长时运行要能回退：检查点、快照、强制停止。

不提升模型智力；让错误可发现、可停止、可复现。
01 工具注册与参数校验

输入是否合法、类型是否匹配；非法提议直接拦截

02 沙箱与权限

只读/写分离；权限、网络、目录范围先限制再执行

03 超时与重试

失败不无限死循环；设置超时熔断与最大重试次数

04 结果验证

结果对不对；通过独立测试与断言检查，不轻信模型自夸

05 回滚与停止

检查点、快照、幂等；异常时强制停止

06 日志与复现

记录每一次调用与返回，全流程轨迹可审计、可复盘

模型提供概率；harness 提供边界与退路。
permissions · sandbox · retries · verification · stop22 / 33

05 / AI × math

生成 → 验证 → 搜索

生成器给候选，验证器给信号；DAG 管依赖，MCTS 管下一步。

生成 · LLM→ 验证 · Lean / 测试 / 数值→ 搜索 · best-of-N / 树 / 进化↺

没有验证器，无法规模化；没有搜索，只能靠运气。

DAG · 结构

节点：引理 / 子目标；边：前提 → 结论；无环，已证引理可复用。

MCTS · 策略
